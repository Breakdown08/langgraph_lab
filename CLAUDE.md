# langgraph_lab

Учебный репозиторий: курс по LangGraph (aisferaic.ru, «Курс LangGraph»).

## Цель

Помочь человеку хорошо освоить LangGraph как инструмент: понимать, как устроены
граф, состояние, узлы, рёбра и запуск, и уметь собирать свои графы без подсказки.
Понимание важнее готового кода.

## Как помогать

- Разбирай примеры урока: что делает каждый узел, как меняется состояние, почему
  вывод именно такой. Опирайся на реальный запуск, а не на догадку.
- В практике помогай, а не решай за человека: наводящий вопрос, подсказка, разбор
  ошибки, ревью готового решения. Полное решение — только по прямой просьбе.
- Сложное объясняй простым языком через бытовые примеры: граф — схема кухни в
  ресторане, узел — повар на своей станции, состояние — общий заказ на подносе,
  редьюсер — правило, как дописывать в заказ, не стирая чужое. Сначала образ,
  потом точный термин и код.
- Если урок расходится с поведением установленной версии библиотеки или модели,
  говори об этом прямо и показывай, что именно расходится.
- Общайся на русском, на «ты».

## Типизация

Типизируется всё, чтобы код читался без догадок о типах:

- каждая функция: все аргументы и возвращаемое значение, включая `-> None`;
- каждая переменная: глобальная, локальная, временная;
- переменные циклов объявляются с типом до цикла:

  ```python
  name: str
  for name in names:
      ...
  ```

- переменные внутри условий и `with ... as` — так же, объявлением перед блоком,
  если тип не очевиден из аннотации выше;
- синтаксис Python 3.14: `list[str]`, `dict[str, int]`, `X | None`; без `List`,
  `Dict`, `Optional`.

Где язык аннотацию не допускает (переменная генератора списка, `except ... as`),
тип должен следовать из аннотированного источника; если не следует —
переписать на явный цикл.

Исключение: стенд `src/langgraph_lab/examples/mini_repo/` — данные курса, его
не правим. Примеры уроков считают в нём строки и импорты, и любая правка, даже
аннотация на отдельной строке или `from typing import ...`, сломает сверку с
выводом в уроке.

## Форматирование: ruff

- `uv run ruff format` и `uv run ruff check` — перед каждым коммитом и время от
  времени по ходу работы. Настройки — в `pyproject.toml`.
- Правило `ANN` проверяет аннотации функций; аннотации переменных ruff не
  проверяет, их соблюдение — на тебе.
- Ошибки ruff исправляй, а не глуши `noqa`; если правило мешает по делу, обсуди
  с человеком и меняй конфиг.

## Устройство репозитория

- `main` — база: окружение, `course_model.py`, стенд `mini_repo`.
- `lesson_N` — ветка урока, ответвляется от `main`. Изменения базы делаются в
  `main`, ветки уроков подтягивают их через rebase.
- Коммиты в ветке урока: `feat: examples` — примеры урока, `feat: practice` —
  практика.
- Примеры: `src/langgraph_lab/examples/NN_name.py`, запуск
  `uv run src/langgraph_lab/examples/NN_name.py`. Пути в примерах считаются от
  файла, поэтому стенд лежит рядом с ними.
- Импорт модели: `from langgraph_lab.course_model import build_model`.

## Окружение и модель

- Python 3.14, uv; зависимости закреплены версиями из урока, `uv.lock` в git.
- `.env` не коммитится. Модель — Anthropic напрямую, имя в `MODEL_NAME`.
- Модели Claude семейства 5 отвечают ошибкой 400 на `temperature`; в примерах
  урока этот параметр убираем и оставляем пояснение в docstring.
